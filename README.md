# movie-app
I'm using this pet project to practice my work with Python and SQLite. I built a simple database of movies and categories which I can add to and/or update based on my latest interests and which movies I've watched. There is a lot of room for growth within the database, but based on the movies that are currently on my Watch List, these categories have made the most sense.

As the journey around this project grows, I hope to bring in further details such as specific genres, release year, and director. I also hope to eventually use this project to program a Raspberry Pi.

### Columns
<pre>
id: Primary, Ascending Key
name: Movie Name
style: Live vs Animated
genre: Comedy vs Tragedy
theme: War vs Not War
character_type: Human vs Animal
watched: Binary
</pre>
